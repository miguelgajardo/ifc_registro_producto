Proyecto de interfaz de registro de producto.

Para la instalación:

1 - Clonar el repositorio público: git@github.com:miguelgajardo/ifc_registro_producto.git
2 - Configurar la base de datos con el documento de definición DDL_REGISTRO-PRODUCTO.sql
3 - Insertar los datos de pruebas para monedas, bodegas y sucursales del documento DML_REGISTRO-PRODUCTO.sql
4 - Configurar la conexión de base de datos en el includes/database.php con las credenciales:
    'mysql:host=localhost;dbname=ifc_registro_productos;charset=utf8','root',''
5 - Para el desarrollo de esta interfaz, se ha utilizado el servicio XAMPP. Asegúrese de incluir la carpeta del proyecto dentro del servidor según corresponda.
    Ej: C:\xampp\htdocs\registro_productos
